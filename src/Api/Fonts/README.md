# Calibri fallback

Unmodified Carlito Regular and Bold from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/carlito), retrieved 2026-09-23. Distributed under the included SIL Open Font License.

[Carlito](https://github.com/googlefonts/carlito) was designed with Calibri-compatible metrics. The API embeds it as a fallback when Calibri is absent, avoiding the much wider system fallback on a clean Mac. Installed Calibri remains preferred, preserving existing Windows rendering. Font substitution is not a guarantee of pixel-identical output; physical label acceptance still happens on the target Windows installation.
