Set up Faethon

Set up this Windows PC for Faethon. PostgreSQL will keep the data on this PC. You can connect to a server instead when that deployment is ready.

1. Install PostgreSQL 17

Install PostgreSQL 17 with command-line tools on port 5432. Its installer may request administrator approval.

2. Connect and initialize

Fresh installation only. Existing databases are never overwritten.

The server must already be running Faethon and have its own database and backups.

Faethon is ready

Use this setup key to create the first administrator account. Keep it until the account is created.
