# Ελληνικός οδηγός χρήσης

[Άνοιγμα οδηγού PDF](faethon-odigos-chrisis.pdf)

Ο οδηγός περιλαμβάνει 12 σελίδες και 11 πραγματικά στιγμιότυπα της εφαρμογής, με αναλογία 16:9. Αποτυπώνει τις λειτουργίες της 24.09.2026.

## Αρχεία

- `build_guide.py`: επεξεργάσιμο ελληνικό κείμενο και κώδικας σελιδοποίησης. Κάθε ενότητα αρχίζει με `new(...)`, μετά τις βοηθητικές συναρτήσεις.
- `screenshots/`: τα στιγμιότυπα PNG που ενσωματώνονται στο PDF, σε 1440 × 810 pixels.
- `requirements.txt`: οι εκδόσεις των βιβλιοθηκών δημιουργίας.
- `faethon-odigos-chrisis.pdf`: το έτοιμο έγγραφο, με συνδέσμους περιεχομένων και σελιδοδείκτες.

Οι γραμματοσειρές Carlito χρησιμοποιούνται από τον υπάρχοντα φάκελο `src/Api/Fonts` του αποθετηρίου. Δεν χρειάζεται να τρέχει η εφαρμογή για να δημιουργηθεί ξανά το PDF.

## Δημιουργία PDF

Με Python 3.10 ή νεότερη, από τη ρίζα του αποθετηρίου:

```sh
python3 -m venv docs/user-guide/.venv
docs/user-guide/.venv/bin/python -m pip install -r docs/user-guide/requirements.txt
docs/user-guide/.venv/bin/python docs/user-guide/build_guide.py
```

Στα Windows, χρησιμοποιήστε `py -3` για τη δημιουργία του περιβάλλοντος και `docs\user-guide\.venv\Scripts\python.exe` στις επόμενες εντολές.

Το αποτέλεσμα γράφεται στο `docs/user-guide/faethon-odigos-chrisis.pdf`. Οι διαδρομές υπολογίζονται από τη θέση του script, χωρίς εξάρτηση από συγκεκριμένο υπολογιστή ή τρέχοντα φάκελο.

## Αλλαγές και έλεγχος

1. Επεξεργαστείτε τα κείμενα, τις λεζάντες και τους πίνακες στο `build_guide.py`. Οι συναρτήσεις `p`, `head`, `note`, `shot` και `table` ελέγχουν τα αντίστοιχα στοιχεία.
2. Για νέα στιγμιότυπα, ελέγξτε πρώτα αν η εφαρμογή λειτουργεί ήδη. Ανοίξτε την πραγματική εφαρμογή και καταγράψτε εικόνες 16:9. Διατηρήστε την αναλογία χωρίς παραμόρφωση. Ορισμένες αρχικές λήψεις έχουν λεπτό ουδέτερο περιθώριο επειδή ο browser απέκλεισε τη γραμμή κύλισης.
3. Εκτελέστε το script. Ελέγχει την αναλογία εικόνων, την υπερχείλιση παραγράφων/πινάκων και το αναμενόμενο πλήθος σελίδων.
4. Ανοίξτε το PDF και ελέγξτε κάθε σελίδα: ελληνικούς χαρακτήρες, κείμενα, εικόνες, πίνακες, υποσέλιδα και συνδέσμους. Για έλεγχο με Poppler: `pdftoppm -scale-to 1200 -png docs/user-guide/faethon-odigos-chrisis.pdf /tmp/faethon-guide`.
5. Αν προσθέσετε ή αφαιρέσετε σελίδες, ενημερώστε τα περιεχόμενα, τις παραπομπές, το σύνολο στο υποσέλιδο και το τελικό `assert`.
6. Κάντε commit μαζί το script, τις αλλαγμένες εικόνες και το νέο PDF.

Τα στιγμιότυπα λήφθηκαν στις 24.09.2026 από τοπική εφαρμογή με πραγματικά δεδομένα προϊόντων. Η παραγωγή της προεπισκόπησης ετικέτας ελέγχθηκε, χωρίς αποστολή φυσικής εκτύπωσης.
